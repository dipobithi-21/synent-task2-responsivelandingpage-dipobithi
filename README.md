# synent-task2-responsivelandingpage-dipobithi

BlushCarry Landing Page

Objective

The objective of this project is to design and develop a modern fashion brand landing page for “BlushCarry” using HTML and CSS. The website showcases stylish handbags with a luxury-inspired user interface and responsive layout.

Technologies Used

* HTML5
* CSS3
* Google Fonts
* Responsive Web Design
* Glassmorphism UI

Tools Used

* VS Code

Features

* Elegant Hero Section
* Luxury Fashion Branding
* Responsive Layout
* Product Showcase Section
* Feature Cards
* Hover Effects & Smooth Animations
* Modern Glassmorphism Design

Steps Performed

1. Created the basic HTML structure
2. Designed the hero section with handbag images
3. Added stylish typography and color palette
4. Developed feature and product sections
5. Implemented glassmorphism product cards
6. Added responsive design using media queries
7. Improved hover effects and visual aesthetics
8. Uploaded the project to GitHub repository

Outcome

Successfully developed a responsive and visually appealing fashion landing page with modern UI/UX design principles. The project improved frontend development skills, layout structuring, and responsive design techniques.
